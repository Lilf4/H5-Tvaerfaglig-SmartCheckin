# H5 Tværfaglig SmartCheckin

Dette er en kollektion af mine repositories for det **tværfaglige projekt**.

Du kan enten downloade/klone hele kollektionen med følgende kommando:

```bash
git clone https://github.com/Lilf4/H5-Tvaerfaglig-SmartCheckin.git --recursive
```

Alternativt kan du hente de individuelle repositories hver for sig. Dette kan gøres enten ved at klikke på submodul-referencen, eller via nedenstående links:

| Repo | Link |
|---|---|
| Web API | [H5-Tvaerfaglig-DBWebApi](https://github.com/Lilf4/H5-Tvaerfaglig-DBWebApi) |
| Web App | [H5-Tvaerfaglig-WebApp](https://github.com/Lilf4/H5-Tvaerfaglig-WebApp) |
| Python Test Program | [H5-Tvaerfaglig-QRTest](https://github.com/Lilf4/H5-Tvaerfaglig-QRTest) |
